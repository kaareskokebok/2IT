# Opg 1
0. OPPDATER NODEJS OG NPM:
```bash
sudo npm cache clean -f
sudo npm install -g n
sudo n stable
```
1. Start nodeprosjekt i mappa 1-hei-verden:
```bash
npm init -y
```
2. Installer express:
```bash
npm i express
```
3. Lag `app.js` og `index.html` (som plasseres i public-mappa)
4. Skriv kode slik at når serveren kjører, så vil index.html vises fram med meldingen "Hei verden!".
